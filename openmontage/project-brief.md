# EGregoRA — montage brief

Hand this file, and `skills/egregora-house-style.md`, to the coding assistant
driving OpenMontage.

- **Pipeline:** `documentary-montage` (retrieval-first thematic montage).
- **Footage:** prefer the clips in `projects/<name>/` pulled from the order's own
  generators by `pull-clips.mjs`. Fill gaps only from free archive sources
  (NASA, Wikimedia Commons, Archive.org / Prelinger, Pexels, Pixabay) so the
  zero-cost path holds. Record provenance for every asset.
- **Thematic question:** one sentence, set per film. Example — *What does a
  nervous system see when it looks at the sky?*
- **Tone register:** contemplative, unhurried, Adam Curtis by candlelight.
- **Duration:** 60–120 seconds unless asked otherwise.
- **Music:** required. Offline-first (Piper TTS for any narration, royalty-free
  or generated score). Never ship silent without an explicit instruction.
- **End tag:** one philosophical closing line, overlay mode, gold on near-black.
- **Budget:** cap at $1.00. The free path is the default; paid providers only on
  explicit say-so.
- **Grade:** uniform warm grade across mixed-era footage — gold `#d7b05a`,
  bright `#f3ddaa`, dim `#cbbb93`, ground `#0a090e`.
- **Type:** Cinzel for titles and the end tag, EB Garamond for any body line.
- **Never:** romanticise fascism; the Black Tribunal material is an industrial
  atrocity dressed in stolen runes and must be cut as such. Edward Gregory is a
  *co-founder*, never "the founder"; Jim Rankin is the other co-founder.
