# EGregoRA business cards

Five designs, front and back, generated by `npm run cards`
(`scripts/make-cards.mjs`). Do not hand-edit the files in here: edit the
script and run it again, so the QR codes and the copy cannot drift apart.

## Print specification

| | |
|---|---|
| Trim | 85 × 55 mm |
| Bleed | 3 mm all round (artboard 91 × 61 mm) |
| Safe area | 4 mm inside the trim |
| Colour | RGB in the files; ask the printer to convert, or request a CMYK proof |
| Files | `.svg` is the master and is vector — send this. `.png` is 300 dpi, for previews and for printers who insist on raster. |

## The five

- **The Illuminated** (`01-illuminated`) — Dark and formal: gold rules, the eleven-ray sigil, the creed set small.
- **The Parchment** (`02-parchment`) — Cream stock, ink and gold: the quietest of the five, and the cheapest to print.
- **The Seam** (`03-seam`) — The Moebius emblem at full width, type pushed to the edges. The one to hand to a stranger.
- **The Ledger** (`04-ledger`) — Prints the grading key itself — the thing that makes the order different, on the card.
- **The Plate** (`05-plate`) — An engraved sky across both faces — the showpiece, and the one that wants good stock.

## The codes

- Front of every card: QR to https://egregora.hatchable.site/ — the introduction.
- Back of every card: QR to https://egregora.hatchable.site/join/ — the sign-up page.

Both are generated at error-correction level Q, which tolerates about 25%
damage, so the cards survive a thumbprint and a wet pocket. Test a printed
proof with two different phones before ordering a thousand.
